CREATE A CATEGORY-BASED COLOR SYSTEM FOR THE ENTIRE WEALTH & SCRUBS WEBSITE

I want Wealth & Scrubs to have a consistent overall brand, but I do NOT want every category to use the exact same color palette.

Each main category should have its own coordinated color scheme so visitors can visually recognize what section they are in.

IMPORTANT:
The category color palette should also carry through to every post/article that belongs to that category.

Do NOT assign random colors to individual pages.

Think of each category as a mini visual identity inside the larger Wealth & Scrubs brand.

The entire site should still feel cohesive, feminine, polished, glamorous, modern, upscale, and recognizable as Wealth & Scrubs.

GLOBAL WEALTH & SCRUBS BRAND RULES

Across all categories, keep these elements consistent:

* Same logo treatment
* Same typography system
* Same heading hierarchy
* Same general button style
* Same icon style
* Same spacing system
* Same border-radius logic
* Same sparkle/glamour level
* Same responsive behavior
* Same polished luxury feel
* Same accessibility standards
* Same overall design quality

The category palette should change.

The entire design language should NOT change.

Avoid making every category look like a completely different website.

Use category colors through:

* Section backgrounds
* Accent lines
* Buttons
* Borders
* Icons
* Small decorative elements
* Highlight boxes
* Hover states
* Links
* Category badges
* Subtle gradients when appropriate

Do not overwhelm pages with every color in the palette at once.

Use darker and richer colors for structure, lighter colors for readability, and metallic/gold tones as accents.

CATEGORY ASSIGNMENT RULE

Every article/post should inherit the palette of its parent category.

Examples:

A travel article under Travel Savings should use the Travel Savings palette.

A side-hustle article under Money & Side Hustles should use the Money & Side Hustles palette.

A nursing article under Nursing Life should use the Nursing Life palette.

Do not create one-off palettes for individual posts unless I specifically request it.

⸻

DESIGN IMPLEMENTATION

Create reusable category theme variables or design tokens rather than manually coding every page.

For each category, define reusable values such as:

–category-primary
–category-secondary
–category-dark
–category-accent
–category-light
–category-background
–category-text
–category-border

Use the site architecture and existing technology appropriately.

The goal is to make category styling easy to maintain and consistent.

If possible, category posts should automatically inherit the correct theme based on category assignment.

Do not duplicate unnecessary CSS across pages.

⸻

COLOR BALANCE RULE

Do not use every palette color equally.

General hierarchy:

60% neutral/light background
25% category primary and secondary colors
10% darker structural color
5% metallic/accent color

Gold should primarily be an accent.

Do not make entire large sections bright metallic gold.

Text must always remain readable.

Maintain proper contrast ratios.
